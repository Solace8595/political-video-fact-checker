# Система автоматической верификации фактов политических выступлений на основе методов обработки естественного языка

Разработка программной системы для анализа политических видеоматериалов: выступлений, интервью, дебатов и новостных роликов. Система преобразует речь из видео в текст, выделяет фактические утверждения, ищет подтверждающие или опровергающие сведения в открытых источниках и формирует отчёт с обоснованием результатов.

## Пользователи:
Любые пользователи сети Интернет

## Требования:
1. Пользователь может загрузить видеофайл или указать ссылку на видеоматериал.
2. Система извлекает аудиодорожку и преобразует речь в текст.
3. Система выделяет фактические утверждения и классифицирует их по заданным типам.
4. Пользователь может проверять и редактировать выделенные утверждения.
5. Система ищет связанные сведения во внешних информационных источниках.
6. Система использует только определённый список источников, которые являются надёжными
7. Система сопоставляет утверждения с найденными доказательствами и формирует статус проверки.
8. Пользователь может просматривать обоснование результатов и использованные источники.
9. Система формирует отчёт по результатам анализа.

## Дополнительный контекст:
1. Система не объявляет сведения абсолютной истиной. Она представляет доступные доказательства, объясняет основания результата и указывает на недостаточность информации, если проверить утверждение не удалось.
2. Система использует только определённый источники из списка, чтобы сузить рамки поиска и использовать только проверенные медиа.
